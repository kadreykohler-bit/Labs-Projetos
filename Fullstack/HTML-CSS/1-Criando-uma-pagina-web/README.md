# Minha Jornada na Tecnologia

Página pessoal criada como exercício introdutório de HTML. O conteúdo apresenta uma trajetória profissional e de estudos, interesses em tecnologia e um link para o perfil no GitHub.

## Conteúdo praticado

- Estrutura básica de um documento HTML em português.
- Hierarquia de títulos, parágrafos e listas.
- Ênfase e marcação de trechos de texto.
- Link externo com atributos de segurança.

## Como visualizar

Abra `index.html` em um navegador. O projeto é estático e não requer instalação de dependências nem servidor.

## Estrutura

- `index.html`: conteúdo e marcação da página.
