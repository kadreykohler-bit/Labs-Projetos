# Landing Page da Trilha de CSS da DIO

Landing page de divulgação da Trilha de CSS da DIO. A página apresenta a proposta do curso, os conteúdos de aprendizagem, uma chamada para inscrição e uma seção sobre desafios profissionais.

## Seções da página

- Banner de apresentação da trilha e botão de inscrição.
- Conteúdo do curso em `#course-content`.
- Chamada “Transforme o mundo com a gente”.
- Seção de desafios profissionais e link para a DIO.

## Tecnologias

- HTML para a estrutura das seções.
- CSS em `css/style.css` para o layout e a identidade visual.
- Imagens em `images/`.

## Como visualizar

Abra `src/index.html` em um navegador. Esta é uma página estática; os botões e chamadas são elementos visuais e não há aplicação de inscrição integrada.
