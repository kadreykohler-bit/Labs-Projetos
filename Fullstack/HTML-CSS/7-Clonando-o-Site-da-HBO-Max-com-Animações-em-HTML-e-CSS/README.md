# Catálogo de Entretenimento com Animações

Protótipo estático de uma página de streaming inspirado na HBO Max. A interface combina navegação, banner principal e catálogo de filmes e séries, com animações de entrada e efeitos de interação feitos em CSS.

## Elementos da página

- Menu com links para Início, Séries, Filmes e Originais.
- Banner principal com chamada para assinatura.
- Catálogo com quatro cards ilustrativos de filmes e séries.
- Animações de entrada e transições em elementos interativos.
- Grade do catálogo adaptada para telas menores com media queries.

## Tecnologias

- HTML para a estrutura do protótipo.
- CSS em `css/style.css` para o catálogo, responsividade, animações e transições.
- Imagens em `img/`.

## Como visualizar

Abra `src/index.html` em um navegador. O projeto é uma reprodução visual para estudo: não possui autenticação, assinatura ou reprodução de conteúdo.
