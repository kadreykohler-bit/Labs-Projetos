# Layout de uma Página de Vídeos

Reprodução estática de uma interface inspirada no YouTube, construída com HTML e CSS. O layout inclui cabeçalho com controles visuais, menu lateral, filtros por categoria e uma grade de vídeos ilustrativos.

## Elementos da interface

- Cabeçalho com menu, busca, botão de criação, notificações e perfil.
- Navegação lateral com links como Início, Shorts e Inscrições.
- Categorias como Música, Programação, Tecnologia e Jogos.
- Grade com miniaturas, títulos de vídeos, canais e visualizações.

## Tecnologias

- HTML para a estrutura da interface.
- CSS em `css/style.css` para o layout e a apresentação visual.
- Miniaturas em `img/`.

## Como visualizar

Abra `src/index.html` em um navegador. A busca, os filtros e os controles são apenas parte do protótipo visual; não há reprodução de vídeos ou integração com o YouTube.
