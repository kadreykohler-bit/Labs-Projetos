# Layout Responsivo Inspirado no Discord

Página estática inspirada na apresentação do Discord, com navegação, área de destaque, botões de download e seções ilustradas sobre comunidades e conversas. O CSS adapta o layout para diferentes larguras de tela.

## Seções

- Navegação com links para Download, Nitro, Discover, Safety e Support.
- Banner principal “IMAGINE UM LUGAR...” com chamadas para ação.
- Seções sobre espaços para comunidades, conversas e grupos.
- Área final de chamada para download.

## Tecnologias

- HTML para a estrutura da página.
- CSS em `css/style.css`, incluindo media queries para telas menores.
- Ilustrações em `img/`.

## Como visualizar

Abra `src/index.html` em um navegador. Redimensione a janela para observar os ajustes responsivos. Os links e botões são elementos de apresentação e não implementam os serviços do Discord.
