# Enciclopédia de Automação Industrial

Página informativa sobre automação industrial, organizada como um artigo com navegação lateral. Os links internos levam às seções sobre CLPs, sensores e sistemas de controle.

## Conteúdo

- Introdução à automação industrial.
- Seção sobre CLPs (Controladores Lógicos Programáveis).
- Seção sobre sensores.
- Seção sobre sistemas de controle.
- Navegação entre assuntos e índice do artigo.

## Tecnologias

- HTML para a estrutura do artigo e seus links de navegação.
- CSS Grid em `css/style.css` para organizar a barra lateral, o conteúdo e os links do artigo.
- Logo do projeto em `img/lg.png`.

## Como visualizar

Abra `src/index.html` em um navegador. Não há dependências externas nem etapa de build.
