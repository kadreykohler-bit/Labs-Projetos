# Site da Clínica Clarus

Site institucional estático para a Clínica Clarus, com páginas de apresentação, informações sobre a clínica, horários de atendimento e contato. A navegação entre as páginas é feita por links no menu.

## Páginas

- `src/index.html`: página principal da clínica.
- `src/sobre.html`: informações sobre a clínica.
- `src/horario.html`: horários de atendimento.
- `src/contato.html`: dados de contato, endereço e formulário visual.

## Tecnologias

- HTML para o conteúdo e a navegação.
- CSS em `css/base.css` para os estilos compartilhados.
- Imagens em `img/`.

## Como visualizar

Abra `src/index.html` em um navegador e use o menu para visitar as demais páginas. O projeto é estático e não requer instalação de dependências.
