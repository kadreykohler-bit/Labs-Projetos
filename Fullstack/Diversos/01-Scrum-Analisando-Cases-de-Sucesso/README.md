# Análise do Scrum na Intel

Este projeto analisa o estudo de caso *Agile Project Development at Intel: A Scrum Odyssey*, sobre a adoção do Scrum em equipes de desenvolvimento da Intel. O trabalho discute os motivos para a mudança em relação ao modelo tradicional, a escolha do framework, os resultados relatados e possíveis melhorias para a implementação.

## Arquivos

- `analise.md`: análise crítica do estudo, organizada em introdução, discussão das questões propostas e conclusão.
- `referencias.md`: referência do estudo de Pat Elwer e material complementar sobre o Scrum.

## Como consultar

Abra `analise.md` para ler a análise e `referencias.md` para acessar as fontes. Os documentos estão em Markdown; não é necessário instalar dependências.
