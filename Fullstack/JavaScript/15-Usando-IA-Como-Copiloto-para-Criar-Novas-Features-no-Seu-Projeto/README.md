# Prompts para Usar IA como Copiloto de Desenvolvimento

Coleção de prompts em português para orientar um assistente de IA em diferentes etapas do trabalho de desenvolvimento: implementar código, responder dúvidas, planejar mudanças ou estudar um assunto.

## Modos disponíveis

- **Agent**: transformar requisitos em alterações de código.
- **Ask**: explicar e diagnosticar sem alterar arquivos.
- **Plan**: elaborar um plano de implementação antes de codificar.
- **Study**: ensinar conceitos e apoiar o aprendizado.

## Organização

- `prompts/original/`: versões originais dos prompts.
- `prompts/editados/`: versões revisadas e personalizadas.

## Como usar

Abra o arquivo do modo desejado, copie o conteúdo e use-o nas instruções do seu assistente de IA. Compare os arquivos `original` e `editados` para acompanhar as alterações. Estes arquivos são instruções em Markdown, não um programa executável.
