# Planejamento de um Gerenciador de Podcasts

Este projeto contém a especificação inicial de um aplicativo para reunir episódios de vídeo em categorias, inspirado em uma plataforma de streaming. A ideia inclui listar episódios e permitir a busca pelo nome do episódio.

## Estado atual

O material presente é de planejamento: `docs/app.md` descreve o domínio, as funcionalidades desejadas e exemplos de dados para a API. Ainda não há código-fonte da aplicação na pasta `src/`. Por isso, os comandos de execução configurados no `package.json` apontam para arquivos que não estão disponíveis e o projeto ainda não pode ser iniciado.

## Estrutura

- `docs/app.md`: proposta do aplicativo, funcionalidades e formato de resposta esperado.
- `package.json`: metadados e scripts previstos para desenvolvimento e build.
- `tsconfig.json`: configuração prevista para TypeScript.

## Próximos passos possíveis

1. Implementar a API e os dados de episódios em `src/`.
2. Criar os arquivos de entrada referenciados pelos scripts do `package.json`.
3. Instalar as dependências necessárias e validar os endpoints planejados.
