# Heróis e Classes em JavaScript

Exercício de orientação a objetos que define a classe `Heroi` e cria personagens com nome, idade e tipo. O método `atacar()` escolhe a descrição do ataque de acordo com o tipo do herói: mago, guerreiro, monge ou ninja.

## Conceitos praticados

- Classes, construtores e instâncias.
- Métodos e propriedades de objetos.
- Condicionais com `switch`.
- Interpolação de strings com template literals.

## Como executar

Com o Node.js instalado, execute na pasta do projeto:

```bash
node index.js
```

O resultado dos ataques de três heróis será exibido no terminal. Não há dependências externas.
