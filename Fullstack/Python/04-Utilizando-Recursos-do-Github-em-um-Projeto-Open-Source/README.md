# Explorando Recursos do GitHub — DIO

## Sobre o projeto

Este repositório foi criado como parte de um desafio prático da Digital Innovation One (DIO), com o objetivo de estudar e compreender os recursos do GitHub e os conceitos de colaboração em projetos Open Source.

## Objetivos

- Compreender o funcionamento do Git e do GitHub.
- Conhecer os principais comandos Git.
- Aprender sobre repositórios e branches.
- Entender como funciona o Fork.
- Conhecer Issues e Pull Requests.
- Explorar formas de colaboração em projetos Open Source.
- Organizar e documentar os conhecimentos adquiridos.

## Tecnologias e ferramentas

- Git
- GitHub
- Visual Studio Code
- Markdown
