# GitHub — Plataforma de Hospedagem e Colaboração

## 1. O que é GitHub?

O GitHub é uma plataforma de hospedagem de repositórios Git que permite armazenar projetos, acompanhar alterações e colaborar com outros desenvolvedores.

É muito utilizado no desenvolvimento de software e em projetos Open Source.

## 2. Principais recursos do GitHub

### Repositories (Repositórios)
Espaços utilizados para armazenar arquivos, códigos e documentação de projetos.

### Fork
Permite criar uma cópia de um repositório de outra pessoa na sua própria conta do GitHub.

### Issues
Permitem registrar problemas, sugestões, melhorias e tarefas relacionadas ao projeto.

### Pull Requests
Permitem propor alterações em um repositório e solicitar que elas sejam analisadas antes de serem incorporadas ao projeto original.

### Branches
Permitem desenvolver funcionalidades ou realizar modificações sem alterar diretamente a versão principal do projeto.

### README
Arquivo utilizado para apresentar o projeto, explicar seus objetivos e fornecer instruções de utilização.

## 3. Diferença entre Git e GitHub

| Git | GitHub |
|---|---|
| Sistema de controle de versão. | Plataforma de hospedagem de repositórios Git. |
| Funciona localmente no computador. | Funciona pela internet. |
| Registra alterações nos arquivos. | Permite compartilhar e colaborar em projetos. |
| Utiliza comandos no terminal. | Oferece interface para gerenciar projetos. |

## 4. Colaboração em projetos

O GitHub facilita o trabalho colaborativo por meio de recursos como:

- Fork de repositórios.
- Criação de branches.
- Registro de Issues.
- Envio de Pull Requests.
- Revisão de código.
- Discussões entre desenvolvedores.

## 5. Importância do GitHub

O GitHub é importante para:

- Construir um portfólio profissional.
- Compartilhar projetos.
- Participar de projetos Open Source.
- Trabalhar em equipe.
- Acompanhar o desenvolvimento de software.
- Conhecer práticas utilizadas no mercado de tecnologia.
