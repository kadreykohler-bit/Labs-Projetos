# Desafios de Algoritmos em Python com GitHub Copilot

## Sobre o projeto

Projeto desenvolvido durante a formação da DIO, com o objetivo de
praticar algoritmos em Python utilizando inteligência artificial
como ferramenta de apoio ao desenvolvimento.

## Objetivos

- Resolver desafios de programação.
- Praticar lógica de programação com Python.
- Utilizar o GitHub Copilot para auxiliar na implementação.
- Analisar e compreender códigos sugeridos pela IA.
- Documentar as soluções desenvolvidas.

## Tecnologias utilizadas

- Python
- GitHub Copilot
- Visual Studio Code
- Git
- GitHub
